# Support

nimblescape Markdown Comment Links is free and open source. Ask questions and
report problems in the
[issues on GitHub](https://github.com/nimblescape/nimblescape-markdown-comment-links/issues).
Search the open and closed issues first. The README describes
[which targets a link resolves](https://github.com/nimblescape/nimblescape-markdown-comment-links/blob/main/README.md#link-resolution)
and [in which files it finds links](https://github.com/nimblescape/nimblescape-markdown-comment-links/blob/main/README.md#files).

## What to include in a report

- The version of the extension (the Extensions view shows it) and of VS Code
  (command **Help: About**).
- Your operating system and its version, for example Windows 11, macOS 15 or
  Ubuntu 24.04.
- Where the folder of the workspace is: on your computer, on a remote host
  (for example over SSH, in WSL or in a dev container), or in a virtual
  workspace.
- The language of the file, the comment line with the link, and the path of
  the file and of the target, relative to the workspace folder. For a link to
  a heading, also the heading line of the target.
- When the target opens in an editor other than the text editor: the value
  of the setting `workbench.editorAssociations`.
- What you did, what you expected, and what happened, with the exact text of
  each message.

## Before you post

An issue is public. A comment, a path or a heading can contain the names of
your projects and folders, and the user name of your computer. Remove what
you do not want to show. Never post a token or a password. Do not report a
security problem in a public issue: the section
[Security problems](https://github.com/nimblescape/nimblescape-markdown-comment-links/blob/main/docs/security.md#security-problems)
says how to report it.
